# 직업생활 · 노동과 안전 퀴즈

19개 주제별 핵심 요약과 57개 퀴즈(객관식·연결·빈칸)를 제공합니다.

- 핵심 요약: 주제별 개념을 읽고 퀴즈·서술형 연습으로 이동
- 문제별 훈련: 즉시 채점, 해설, 힌트, 재시도
- 오답 복습: 마지막 답변이 틀린 문제 다시 풀기
- 19문제 실전 퀴즈: 주제마다 한 문제씩, 종료 후 정답·해설 확인
- 서술형 연습: 답안 저장, 핵심어 점검, 예시 답안 비교

## GitHub Pages 게시

1. ZIP을 풀고 안의 파일들을 GitHub 저장소 루트에 함께 업로드합니다.
2. Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
3. 업로드한 브랜치(보통 main)와 /(root)를 선택하고 Save를 누릅니다.

빌드·설치가 필요 없는 정적 사이트입니다. docs 폴더에 업로드했다면 Pages에서 /docs를 선택하세요. 모든 파일 경로는 상대 경로입니다.

## 로컬 사용

standalone.html을 브라우저에서 열면 퀴즈를 사용할 수 있습니다. 핵심 정리 다운로드는 notes.md를 같은 폴더에 둘 때 작동합니다.

## 학습 기준

사용자가 첨부한 교재 요약을 바탕으로 제작했습니다. 중복 항목을 합쳤으며 취소선 내용은 제외했습니다. 육아휴직 기간·급여 및 구직급여 관련 수치는 첨부 자료 기준으로 학습하며 현행 제도 안내가 아닙니다. 서술형 점검은 핵심어 포함 여부만 확인하는 참고 기능입니다. 학습 기록은 해당 브라우저에 저장됩니다.
